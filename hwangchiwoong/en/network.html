Project 2 · University Journalists Network website · Live

Real photos, not generated art: rebuilding a nonprofit's website

I rebuilt the website of the student-journalism nonprofit I once chaired. Two goals: show only what the organization has actually done, and let staff who don't code edit it themselves.

Planning and editing: Chiwoong Hwang · Built by Claude · Launched November 19, 2026 · univjournalist.network

SEOUL — The University Journalists Network is a nonprofit founded in March 2020. Each year it holds a conference that draws about 100 student journalists from across Korea, and it runs a free hands-on training academy and an awards program. When a school cracks down on its student press, the Network forms a response team; it also counsels students whose editorial independence is under threat.

The website is how people learn about this work. But as the programs grew, the number of people who could update the site did not. [One or two sentences on why I decided to rebuild it]

Three editorial calls

One: no generated images. The site uses no AI-generated images, only photos the organization took at its own events. A journalists' organization should show only things that actually happened.

Two: staff edit it themselves. Changing even one line of a notice meant changing code. We decided to move the text and settings into a Cloudflare database so staff can edit them from an admin screen. How to do it is written up in a separate staff guide.

Three: the site outlasts the people. Student-press groups turn over every year. The code repository moved from a personal account to the organization's account, so the site stays with the organization when whoever runs it leaves.

Launch

The domain and content were already in place. On November 19, 2026, the draft became the official site.

Deployment reconnected through a new project

The deployment link was broken, so changes weren't reaching the live site. Along with moving the repository to the organization's account, we reconnected it through a new Cloudflare deployment project and switched to the official site the same day.
